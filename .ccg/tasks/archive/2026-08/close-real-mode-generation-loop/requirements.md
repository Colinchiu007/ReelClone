# 接通 Temporal 真实模式生成主链路

## 目标

让 Temporal Worker 在 `TEMPORAL_MOCK_MODE=false` 时不再因内置 Activity 的占位异常而阻断视频生成工作流，并复用仓库既有的计费、对象存储、Work 状态和 Redis 通知边界。

## 范围

1. 追踪视频生成工作流调用的计费、OSS、状态更新、Redis 通知和订阅消息 Activity。
2. 为本地可验证的真实模式实现可配置依赖或服务适配，避免向 Temporal 包直接耦合 Nest 应用服务。
3. 补齐成功、失败和取消时的积分与状态一致性测试。
4. 保留云凭据、真实 OSS、真实微信和实际部署验收为外部依赖，不在代码中硬编码或伪造。

## 非目标

- 不接入或输出任何生产云凭据、支付私钥、微信密钥或短信通道。
- 不修改微信支付实现。
- 不承诺没有真实 Provider/云环境的端到端生产验收。
