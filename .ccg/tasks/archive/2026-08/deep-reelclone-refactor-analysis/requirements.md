# 需求说明

## 目标

基于当前 `master` 的实际实现，深度理解 ReelClone 的架构、模块边界、核心业务链路、数据一致性、测试与交付体系，并形成一份可执行的重构分析报告。

## 范围

- 识别实时技术栈、应用与库的依赖关系。
- 追踪关键业务链路，尤其是生成、任务编排、计费和状态持久化。
- 评估模块边界、重复实现、耦合、复杂度、安全性、可观测性和测试覆盖。
- 区分已合并实现、遗留文档和未落地设想。
- 给出按价值、风险、成本排序的重构路线图与验收标准。

## 非目标

- 不在本任务中直接重构业务代码。
- 不修改用户已有的未跟踪配置和其他任务记录。
- 不把本地测试结果等同于生产环境验证。

## 交付物

- 项目级 Markdown 重构分析报告。
- CCG 双模型分析与审查记录。
- 完成后归档本任务。
