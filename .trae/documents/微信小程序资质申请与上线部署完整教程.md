# 微信小程序资质申请与上线部署完整教程

> 基于 ReelClone 项目的全方位指南，涵盖从注册到上线的每一步操作，以及常见问题和解决方案。

---

## 一、总体流程概览

```
注册小程序账号 → 主体认证（企业/个体户）→ ICP备案 → 开通微信支付（如需）
→ 选择服务类目 → 申请AI深度合成类目（本项目必需）→ 后端部署（HTTPS）
→ 配置服务器域名 → 代码构建上传 → 提交审核 → 发布上线
```

**预计总耗时：** 2-4 周（主要瓶颈在 ICP 备案和审核周期）

---

## 二、注册小程序账号

### 2.1 注册入口

- 访问 https://mp.weixin.qq.com/
- 点击右上角「立即注册」→ 选择「小程序」

### 2.2 主体类型选择

| 主体类型         | 需要的材料                           | 能力差异                                       | 适用场景          |
| ---------------- | ------------------------------------ | ---------------------------------------------- | ----------------- |
| **个人**         | 身份证、手机号                       | 不能认证、不能开通支付、不能使用大部分服务类目 | 个人学习/演示     |
| **企业（公司）** | 营业执照、法人身份证、对公银行账户   | 全部能力，需认证费 300元/年                    | 正式运营（推荐）  |
| **个体工商户**   | 营业执照、法人身份证、法人私户银行卡 | 大部分能力，需认证费 300元/年                  | 小型团队/个人创业 |

**ReelClone 项目建议：** 使用**企业主体**注册。因为本项目涉及 AI 生成、微信支付、深度合成类目，个人主体无法满足资质要求。

### 2.3 注册步骤

1. 填写邮箱（未绑定过微信公众平台的全新邮箱）
2. 邮箱验证（点击确认链接）
3. 选择主体类型（企业/个体户/个人）
4. 填写主体信息：
   - **企业：** 营业执照统一社会信用代码、法人姓名、法人身份证号
   - **个体户：** 营业执照注册号、法人姓名、法人身份证号
5. 填写管理员信息（微信号绑定、手机号）
6. 完成注册

### 2.4 获取 AppID

注册完成后，在小程序后台「开发管理」→「开发设置」中获取：

- **AppID（小程序ID）：** 如 `wx1234567890abcdef`
- 这是项目中所有微信 API 调用的核心凭证

**配置到项目中：**

- [miniprogram/.env.example](file:///d:/Data/projects/ReelClone/apps/miniprogram/.env.example) 中的 `WECHAT_APPID`
- [auth-service/.env.example](file:///d:/Data/projects/ReelClone/apps/auth-service/.env.example) 中的 `WECHAT_APPID` 和 `WECHAT_SECRET`

## 三、主体认证

### 3.1 企业认证流程

1. 登录小程序后台 →「设置」→「基本设置」→「微信认证」
2. 点击「开通」，签署《微信公众平台认证服务协议》
3. 支付认证审核费 **300元/年**（通过微信支付）
4. 填写企业信息：
   - 企业全称、营业执照注册号
   - 组织机构代码（如有）
   - 法人信息
5. 提交认证，等待 **1-5 个工作日** 审核

### 3.2 个体工商户认证

流程与企业基本一致，使用个体工商户营业执照即可。

### 3.3 认证状态

- 认证通过后，小程序名称、头像、介绍等信息会被审核
- 认证有效期 1 年，到期需年审（续费 300元）
- 未认证的小程序功能受限严重

## 四、ICP 备案（必需）

> 自 2023 年 9 月起，微信小程序必须完成 ICP 备案后才可上架。

### 4.1 备案条件

- 已完成微信认证的企业/个体户主体
- 小程序负责人需持有有效身份证

### 4.2 备案材料清单

| 材料                   | 说明                               |
| ---------------------- | ---------------------------------- |
| 主办单位证件           | 营业执照彩色扫描件（清晰完整）     |
| 主体负责人证件         | 身份证正反面彩色扫描件             |
| 小程序负责人证件       | 身份证正反面彩色扫描件             |
| 小程序负责人核验照片   | 现场拍摄，背景纯白色，不遮挡面部   |
| 互联网信息服务承诺书   | 平台自动生成，需签署               |
| 小程序备案真实性核验单 | 平台自动生成                       |
| 前置审批文件           | AI 类需提供算法备案（见第五节）    |
| 补充材料               | 如授权书、党建证明等（视地区要求） |

### 4.3 备案操作步骤

1. 登录小程序后台 →「设置」→「基础信息」→「小程序备案」→「去备案」
2. 填写主体信息：
   - 单位名称、证件号码、通讯地址
   - 主体负责人姓名、身份证号、手机号
3. 填写小程序信息：
   - 小程序名称、负责人姓名、身份证号
   - 服务内容描述（如实填写 AI 视频生成相关功能）
4. 上传证件材料（彩色扫描件，确保清晰完整）
5. 小程序负责人进行**人脸核验**（微信扫码，纯白背景拍摄）
6. 签署承诺书和核验单
7. 提交审核

### 4.4 备案审核流程

```
提交备案 → 平台初审(1-2个工作日) → 工信部短信核验(24小时内) → 通管局审核(1-20个工作日) → 备案成功
```

**关键节点：**

1. **平台初审：** 微信 1-2 个工作日审核，通过后发送站内信通知
2. **短信核验：** 收到工信部发送的短信（号码 12381），**必须在 24 小时内**登录工信部备案官网完成核验
3. **通管局审核：** 各省通信管理局 1-20 个工作日，期间可能有电话回访
4. **备案成功：** 下发小程序备案号

### 4.5 常见问题

| 问题                     | 解决方案                                                         |
| ------------------------ | ---------------------------------------------------------------- |
| 短信核验超时             | 24小时内未核验需重新提交备案，务必收到短信后立即操作             |
| 通管局审核被退回         | 根据退回原因修改信息后重新提交，常见原因：地址不详、电话无人接听 |
| 备案信息与营业执照不一致 | 确保所有填写信息与营业执照完全一致                               |
| 电话回访无人接听         | 保持备案负责人电话畅通，回访电话通常是当地通信管理局号码         |
| 需要前置审批             | AI 类小程序需要《互联网信息服务算法备案》（见第五节）            |

## 五、AI 深度合成类目申请（ReelClone 必需）

> ReelClone 涉及 AI 视频生成、AI 图片生成、AI 文本生成，必须申请「深度合成」类目。

### 5.1 所需类目

根据 ReelClone 的功能范围，需要申请以下服务类目：

| 类目            | 对应功能                                 | 资质要求 |
| --------------- | ---------------------------------------- | -------- |
| 深度合成-AI问答 | AI 文本生成（`pages/workbench/text`）    | 算法备案 |
| 深度合成-AI绘画 | AI 图片生成（`pages/workbench/image`）   | 算法备案 |
| 深度合成-AI换脸 | AI 视频生成（`pages/workbench/video-*`） | 算法备案 |

### 5.2 互联网信息服务算法备案

这是申请深度合成类目的**核心前置条件**。

**什么是算法备案？**

- 根据《互联网信息服务算法推荐管理规定》和《互联网信息服务深度合成管理规定》，提供深度合成服务的平台必须在国家网信办完成算法备案
- 备案网址：https://beian.cac.gov.cn/

**备案所需材料：**

- 企业营业执照
- 法人身份证
- 算法安全负责人信息
- 算法描述文档（算法名称、类型、应用场景、技术原理等）
- 算法安全自评估报告
- 服务协议和隐私政策

**备案流程：**

1. 登录互联网信息服务算法备案系统
2. 填写主体信息
3. 填写算法信息：
   - 算法类型选择「生成合成类（深度合成）」或「生成合成类」
   - 算法名称：如实填写（如"AI视频生成算法"）
   - 应用场景描述：说明小程序中哪些功能使用了该算法
4. 上传算法安全自评估报告
5. 提交审核，等待 **1-3 个月**

**重要提示：**

- 算法备案耗时较长（1-3 个月），务必提前申请
- 如果使用第三方 AI 服务（如 Seedance），需要提供**技术主体的算法备案**，而不仅仅是小程序主体的协议
- 备案通过后会公示在国家网信办官网

### 5.3 在小程序后台申请类目

1. 登录小程序后台 →「设置」→「基本设置」→「服务类目」
2. 点击「添加类目」
3. 选择「工具」→「深度合成-AI问答」（或其他对应类目）
4. 上传资质材料：
   - 《互联网信息服务算法备案》截图或文件
   - 技术主体与小程序主体的关系证明
   - 在用证明（如已备案的其他小程序截图）
5. 提交审核

### 5.4 常见问题

| 问题                                 | 解决方案                                                                             |
| ------------------------------------ | ------------------------------------------------------------------------------------ |
| 审核提示需要算法备案                 | 需先在网信办完成算法备案，再回来申请类目                                             |
| 使用第三方AI服务，没有自己的算法备案 | 需要第三方提供其《互联网信息服务算法备案》，证明其算法类型为"生成合成类（深度合成）" |
| 提供的协议不被认可                   | 不能仅提供合作协议，必须提供实际的算法备案证明                                       |
| 类目审核被拒                         | 根据拒绝原因补充材料，常见为缺少算法备案或备案类型不匹配                             |
| 算法备案类型选择                     | 如果是视频/图片生成选"生成合成类"，如果涉及人脸处理选"生成合成类（深度合成）"        |

## 六、开通微信支付（本项目需要）

> ReelClone 包含套餐积分和订单支付功能，需要接入微信支付 V3。

### 6.1 注册微信支付商户号

1. 访问 https://pay.weixin.qq.com/
2. 点击「接入微信支付」→「注册微信支付商户号」
3. 使用已实名的微信扫码（微信号需绑定银行卡）
4. 填写商户信息：
   - 营业执照信息（与小程序主体一致）
   - 法人身份证信息
   - 对公银行账户信息
5. 提交审核，等待 **1-5 个工作日**
6. 审核通过后，进行**账户验证**（对公账户打款验证或法人微信验证）

### 6.2 绑定小程序与商户号

**方式一：在小程序后台绑定**

1. 小程序后台 →「微信支付」→「关联商户号」
2. 输入商户号，发送绑定邀请
3. 在微信商户平台确认绑定

**方式二：在商户平台绑定**

1. 登录微信商户平台 →「产品中心」→「APPID账号管理」
2. 点击「关联APPID」
3. 输入小程序 AppID，发送绑定邀请
4. 在小程序后台确认绑定

### 6.3 配置微信支付 V3

本项目使用微信支付 V3 接口，需要配置以下信息（配置到根目录 [.env.example](file:///d:/Data/projects/ReelClone/.env.example) 中）：

```env
# 商户号
WECHAT_PAY_MCHID=your_mch_id

# 商户API证书序列号（从商户平台下载证书后获取）
WECHAT_PAY_SERIAL_NO=your_cert_serial_no

# 商户API私钥（从商户平台生成并下载）
WECHAT_PAY_PRIVATE_KEY=-----BEGIN PRIVATE KEY-----\nYOUR_KEY\n-----END PRIVATE KEY-----

# APIv3 密钥（在商户平台设置）
WECHAT_PAY_API_V3_KEY=your_api_v3_key

# 支付结果回调地址（必须是 HTTPS）
WECHAT_PAY_NOTIFY_URL=https://your-domain.com/webhook/wechat-pay
```

**获取步骤：**

1. 登录微信商户平台 →「账户中心」→「API安全」
2. 设置 APIv3 密钥（32 位随机字符串）
3. 申请 API 证书（下载证书文件）
4. 记录证书序列号

### 6.4 常见问题

| 问题                   | 解决方案                                          |
| ---------------------- | ------------------------------------------------- |
| 商户号审核被拒         | 检查营业执照信息是否准确，法人身份是否一致        |
| 支付回调地址配置失败   | 必须使用 HTTPS 域名，且域名已完成 ICP 备案        |
| 证书序列号不正确       | 从商户平台「API安全」页面重新下载证书并获取序列号 |
| 支付时提示商户号未关联 | 确认小程序与商户号已完成绑定并授权                |

## 七、服务器域名配置

### 7.1 域名要求

微信小程序**必须使用 HTTPS** 与服务器通信，且域名需在小程序后台配置。

**支持的协议：**

- `request`（普通请求）：仅 `https`
- `uploadFile`（上传文件）：仅 `https`
- `downloadFile`（下载文件）：仅 `https`
- `connectSocket`（WebSocket）：仅 `wss`

**域名要求：**

- 必须已备案（ICP 备案）
- 必须使用有效 SSL 证书（不支持自签名证书）
- 不支持 IP 地址和端口号
- 每个类型最多配置 20 个域名

### 7.2 配置步骤

1. 登录小程序后台 →「开发管理」→「开发设置」→「服务器域名」
2. 点击「修改」
3. 配置以下域名：

```
request 合法域名：https://api.your-domain.com
uploadFile 合法域名：https://api.your-domain.com
downloadFile 合法域名：https://api.your-domain.com; https://your-oss-bucket.oss-cn-hangzhou.aliyuncs.com
socket 合法域名：wss://ws.your-domain.com
```

4. 保存配置

### 7.3 开发阶段绕过域名限制

在微信开发者工具中：

- 「详情」→「本地设置」→ 勾选「不校验合法域名、web-view（业务域名）、TLS版本以及HTTPS证书」

**注意：** 此选项仅限开发调试，正式发布前必须配置合法域名。

## 八、后端部署

### 8.1 ReelClone 后端架构

ReelClone 采用 NestJS 微服务架构，共 9 个服务 + 1 个 Worker：

| 服务                 | 端口 | 职责                   |
| -------------------- | ---- | ---------------------- |
| auth-service         | 3001 | 微信登录、JWT Token    |
| user-service         | 3002 | 用户信息、手机号绑定   |
| asset-service        | 3003 | 素材资产、OSS 直传     |
| benchmark-service    | 3004 | 竞品视频对标解析       |
| template-service     | 3005 | 模板广场               |
| billing-service      | 3006 | 积分余额               |
| workbench-service    | 3007 | AI 生成任务、作品管理  |
| notification-service | 3008 | 站内通知、微信订阅消息 |
| order-service        | 3009 | 套餐、订单、微信支付   |
| media-worker         | 3010 | Temporal Worker        |

### 8.2 部署方案选择

| 方案               | 适用场景         | 成本 |
| ------------------ | ---------------- | ---- |
| **Docker Compose** | 快速部署、小规模 | 低   |
| **Kubernetes**     | 生产环境、高可用 | 中高 |
| **云服务商托管**   | 省运维、按需扩展 | 中   |

### 8.3 Docker Compose 部署（推荐起步方案）

1. **准备服务器：**
   - 推荐 2核4G 以上配置（AI 生成需要更多资源）
   - 安装 Docker 和 Docker Compose

2. **克隆项目并配置环境变量：**

   ```bash
   git clone <your-repo-url>
   cd ReelClone
   cp .env.example .env
   # 编辑 .env 填写生产环境配置
   ```

3. **关键环境变量配置（生产环境）：**

   ```env
   # 关闭所有 Mock 模式
   WECHAT_MOCK_MODE=false
   TEMPORAL_MOCK_MODE=false

   # 配置真实微信凭证
   WECHAT_APPID=wx你的真实AppID
   WECHAT_SECRET=你的真实Secret

   # 配置微信支付
   WECHAT_PAY_MCHID=你的商户号
   WECHAT_PAY_SERIAL_NO=你的证书序列号
   WECHAT_PAY_PRIVATE_KEY=你的私钥
   WECHAT_PAY_API_V3_KEY=你的APIv3密钥
   WECHAT_PAY_NOTIFY_URL=https://api.your-domain.com/webhook/wechat-pay

   # 配置数据库和Redis（使用生产密码）
   DATABASE_PASSWORD=强密码
   REDIS_PASSWORD=强密码
   JWT_SECRET=至少32位随机字符串
   ```

4. **启动服务：**
   ```bash
   docker-compose up -d
   ```

### 8.4 SSL 证书配置

后端 API 必须使用 HTTPS，推荐方案：

**方案一：Nginx 反向代理 + Let's Encrypt**

```nginx
server {
    listen 443 ssl;
    server_name api.your-domain.com;

    ssl_certificate /etc/letsencrypt/live/api.your-domain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/api.your-domain.com/privkey.pem;

    location / {
        proxy_pass http://localhost:3000;  # API 网关
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

**方案二：云服务商 SSL 证书（推荐）**

- 阿里云/腾讯云提供免费 SSL 证书
- 配置更简单，自动续期

## 九、小程序代码构建与上传

### 9.1 本地构建

```bash
# 进入项目根目录
cd ReelClone

# 安装依赖
npm install

# 构建微信小程序版本
npx taro build --type weapp

# 产物输出到 apps/miniprogram/dist/
```

### 9.2 配置生产环境变量

在 `apps/miniprogram/.env` 中配置：

```env
NODE_ENV=production
API_BASE_URL=https://api.your-domain.com/api
WECHAT_APPID=wx你的真实AppID
```

### 9.3 使用微信开发者工具上传

1. 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 打开微信开发者工具
3. 选择「导入项目」
4. 选择项目目录：`apps/miniprogram/dist`
5. 填入 AppID
6. 点击「导入」

**预览测试：**

- 在开发者工具中点击「预览」，生成二维码，用微信扫码在手机上测试
- 点击「真机调试」可以进行远程调试

**上传代码：**

1. 点击开发者工具右上角「上传」
2. 填写版本号（如 `1.0.0`）
3. 填写项目备注
4. 点击「上传」

### 9.4 上传后的版本管理

上传成功后，在小程序后台「管理」→「版本管理」可以看到：

- **开发版本：** 刚上传的代码
- **体验版本：** 可设置为体验版，供内部测试
- **线上版本：** 当前发布的正式版本

## 十、提交审核与发布

### 10.1 提交审核前检查清单

- [ ] 小程序已完成 ICP 备案
- [ ] 服务类目已添加且审核通过
- [ ] AI 深度合成类目已申请通过
- [ ] 微信支付已开通并绑定
- [ ] 服务器域名已配置（HTTPS）
- [ ] 后端服务已部署且可正常访问
- [ ] 小程序功能完整，无明显 Bug
- [ ] 隐私协议和用户协议页面已填写完整
- [ ] 小程序名称、头像、介绍已填写
- [ ] 重要功能页面已配置（审核信息中需填写）

### 10.2 填写审核信息

1. 登录小程序后台 →「管理」→「版本管理」
2. 在「开发版本」中找到要提交的版本
3. 点击「提交审核」
4. 填写审核信息：
   - **版本描述：** 如实描述本次更新内容
   - **测试账号：** 如小程序需要登录，需提供测试账号（审核人员测试用）
   - **特殊说明：** 如有需要审核人员特别注意的事项
5. 选择要提交的服务类目
6. 提交审核

### 10.3 审核周期与状态

| 状态     | 说明                           |
| -------- | ------------------------------ |
| 审核中   | 一般 1-7 个工作日，通常 1-2 天 |
| 审核通过 | 可以手动发布上线               |
| 审核失败 | 根据拒绝原因修改后重新提交     |
| 已下架   | 违反平台规则被下架             |

### 10.4 发布上线

审核通过后：

1. 在「版本管理」页面，点击「发布」
2. 小程序正式上线，用户可以搜索和使用

### 10.5 常见审核问题与解决方案

| 问题                     | 原因                       | 解决方案                                                     |
| ------------------------ | -------------------------- | ------------------------------------------------------------ |
| 提示「缺少深度合成类目」 | 未申请 AI 相关服务类目     | 按第五节申请深度合成类目                                     |
| 提示「功能不完整」       | 页面存在空白或未实现的功能 | 确保所有页面功能完整，或隐藏未完成的页面                     |
| 提示「隐私协议缺失」     | 未配置隐私协议             | 在小程序后台「设置」→「基本设置」→「用户隐私保护指引」中配置 |
| 提示「支付功能异常」     | 微信支付未正确配置         | 检查商户号绑定和支付配置                                     |
| 提示「服务器域名未配置」 | 域名未在后台配置           | 按第七节配置合法域名                                         |
| 提示「内容违规」         | 小程序内容违反平台规则     | 检查内容是否涉及敏感信息，确保符合平台规范                   |
| 审核超时                 | 审核队列积压               | 耐心等待，可联系客服催审                                     |
| 被拒后反复提交仍被拒     | 修改不彻底                 | 仔细阅读拒绝原因，必要时联系微信客服（400-830-8300）         |

## 十二、CI/CD 自动化部署（可选）

### 12.1 GitHub Actions 配置

项目已配置 [GitHub Actions](file:///d:/Data/projects/ReelClone/.github/workflows)，可以实现：

- 代码推送自动构建
- 自动运行测试
- 自动上传小程序代码（需要配置微信开发者工具 token）

### 12.2 自动上传小程序代码

使用 [miniprogram-ci](https://developers.weixin.qq.com/miniprogram/dev/devtools/ci.html) 工具：

```bash
# 安装
npm install miniprogram-ci -g

# 上传
miniprogram-ci upload \
  --appid wx你的真实AppID \
  --pkp ./private.key \
  --pkversion 1 \
  --upload-desc "自动部署 v1.0.0" \
  --upload-dest /path/to/dist
```

**获取上传密钥：**

1. 小程序后台 →「开发管理」→「开发设置」→「小程序代码上传」
2. 生成上传密钥，下载 `private.key` 文件
3. 将密钥文件添加到 CI/CD 的 Secrets 中
