## 一、文档说明

### 1.1 目的

本文档是 ReelClone 项目的**全量功能点清单**，基于 31 张目标产品截图逐像素审计得出。每个功能点均与重命名后的截图文件一一关联，确保无视觉能力的 LLM 或下游工程师仅凭文字即可还原界面与交互。

### 1.2 阅读对象

产品经理、UI/UX 设计师、前端工程师、后端工程师、测试工程师、算法工程师、运维工程师。

### 1.3 编号规则

| 编号段 | 含义 |
|--------|------|
| FR-1.x | 首页（Home） |
| FR-2.x | 生成工作台（文本/图片/视频生成） |
| FR-3.x | 对标解析（Benchmark） |
| FR-4.x | 灵感广场 / 推荐（Inspiration / Discover） |
| FR-5.x | 个人中心（Profile） |
| FR-6.x | 设置（Settings） |
| FR-7.x | 我的资产（Assets） |
| FR-8.x | 我的作品（Works） |
| FR-9.x | 我的模板（Templates） |
| FR-10.x | 套餐与积分（Billing & Credits） |
| FR-11.x | 关于（About） |

### 1.4 优先级定义

| 优先级 | 定义 |
|--------|------|
| P0 | MVP 必须实现，缺失则核心流程无法跑通 |
| P1 | 第二阶段补齐，显著提升体验或商业化能力 |
| P2 | 后续迭代，增强运营或企业级能力 |

### 1.5 字段模板说明

每个功能点条目包含以下字段：

```yaml
功能点ID: FR-X.X
功能名称: <中文名称>
所属模块: <模块名>
优先级: P0/P1/P2
触发条件: <用户操作或系统事件>
输入字段: <如有，列出字段名、类型、约束、默认值>
业务规则: <条件→行为的完整规则>
异常处理: <错误场景与系统响应>
关联截图: <重命名后的截图文件名>
```
