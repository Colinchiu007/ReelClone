## 一、服务类目选择与理由

### 1.1 ReelClone 功能概览

ReelClone 是一款面向内容创作者的 AI 短视频创作工具，核心功能包括：

| 功能模块 | 说明 |
|---------|------|
| AI 视频生成 | 文生视频、图生视频（首帧/首尾帧）、3D 建模参考、视频编辑、视频延长 |
| AI 图片生成 | 反推提示词、图生图 |
| AI 文本生成 | 对话模式工作台、文案生成 |
| 对标解析 | 竞品视频链接输入 → 4 维度分析（场景/ASR/OCR/VLM）→ 结构化报告 |
| 模板广场 | 行业标签分类、模板推荐与收藏 |
| 套餐积分 | 订阅计划、积分消费、订单支付（微信支付） |

### 1.2 推荐服务类目

#### 主营类目（必选）

| 一级类目 | 二级类目 | 选择理由 |
|---------|---------|---------|
| **AI 服务** | **深度合成-AI 问答** | ReelClone 接入通义千问/豆包 LLM 提供文本生成、对标解析、提示词优化等 AI 文本能力，属于生成式 AI 深度合成服务，必须选择此类目 |
| **AI 服务** | **深度合成-AI 绘画** | ReelClone 提供 AI 图片生成（图生图、反推提示词）功能，属于 AI 视觉内容生成，需选择此类目 |

#### 辅助类目（建议选择）

| 一级类目 | 二级类目 | 选择理由 |
|---------|---------|---------|
| **工具** | **效率** | ReelClone 定位为创作效率工具，提供一站式 AI 创作能力。选择此类目覆盖工具属性，降低审核对 AI 服务资质的单一依赖 |

### 1.3 类目选择关键说明

1. **AI 服务类目为强制要求**：根据微信 2023-12 版《小程序运营规范》，凡涉及生成式 AI（自动回复、意图识别、内容生成等）的小程序必须添加 AI 服务类目，否则无法通过审核。

2. **深度合成类目不支持个人主体**：AI 服务-深度合成类目仅对企业主体开放，个人小程序无法选择。ReelClone 必须以企业主体注册。

3. **算法备案要求**：选择深度合成类目需提供《互联网信息服务深度合成管理规定》要求的算法备案证明：
   - 方式 A：企业自有算法备案（在 https://beian.cac.gov.cn 完成）
   - 方式 B：使用合作方算法备案 + 合作证明（如 Seedance/火山引擎、通义/阿里云的算法备案截图 + 服务合同）

   **ReelClone 推荐方式 B**：提供火山引擎（Seedance）和阿里云（通义）的算法备案截图 + API 服务合同。

4. **AI 视频生成类目**：目前微信未单独设立"深度合成-AI 视频"类目。AI 视频生成可归入"深度合成-AI 绘画"（视觉内容生成）或与审核沟通确认。这是潜在审核风险点（见第六节）。

5. **虚拟物品支付**：ReelClone 售卖积分套餐（虚拟物品），通过微信支付收款。无需选择电商类目，但需确保：
   - 虚拟物品支付场景合规（不含虚拟货币兑换）
   - 用户协议明确积分性质与退款政策
   - 支付类目选择"虚拟商品"即可

## 五、内容安全审核接入方案

### 5.1 架构概览

```
用户提交生成请求
    ↓
workbench-service (generation.service.ts)
    ↓ enableModeration: true
Temporal video-generation.workflow.ts
    ↓ 视频生成成功后
media.activities.ts → moderateContent(videoKey, thumbnailKey)
    ↓
libs/ai/moderation.service.ts → 关键词黑名单过滤
    ↓
审核通过 → 结算积分 → 通知用户
审核未通过 → 释放积分（退款）→ 标记失败 → 通知用户
```

### 5.2 接入状态

| 检查项 | 文件路径 | 状态 | 说明 |
|-------|---------|------|------|
| 审核服务实现 | `libs/ai/src/moderation/moderation.service.ts` | ✅ 已实现 | MVP 关键词黑名单过滤，覆盖政治/色情/暴力/违法/违禁品/虚假宣传 |
| Activity 实现 | `libs/temporal/src/activities/media.activities.ts` | ✅ 已接入 | `moderateContent` 在真实模式调用 ModerationService，Mock 模式返回通过 |
| 工作流调用 | `libs/temporal/src/workflows/video-generation.workflow.ts` | ✅ 已调用 | `handleSuccess` 中在生成完成后调用 `moderateContent` |
| 审核失败退款 | `libs/temporal/src/workflows/video-generation.workflow.ts` | ✅ 已接入 | 审核未通过时调用 `releaseCredits` 释放积分 |
| 默认开启审核 | `apps/workbench-service/src/workbench/generation.service.ts` | ✅ 已开启 | `enableModeration: true` |

### 5.3 MVP 审核策略

MVP 阶段使用关键词黑名单过滤：

- **审核对象**: 视频 OSS Key、封面 OSS Key 的文本内容
- **敏感词库**: 政治敏感、色情低俗、暴力恐怖、违法犯罪、违禁品、虚假宣传 6 类共 20+ 关键词
- **审核结果**: `passed` / `rejected`（含命中关键词列表与原因）

### 5.4 后续升级接入点

`media.activities.ts` 中 `moderateContent` 函数已预留清晰接入点，后续替换为正式内容安全 API 时只需修改真实模式分支：

| 方案 | API | 适用场景 |
|-----|-----|---------|
| 微信内容安全 | `wx.cloud.security.msgSecCheck` / `imgSecCheck` | 文本/图片审核 |
| 阿里云内容安全 | Green SDK `scanVideo` / `scanImage` | 视频/图片审核 |
| 腾讯云天御 | `TextModeration` / `ImageModeration` | 文本/图片审核 |

**替换步骤**:
1. 在 `media.activities.ts` 真实模式分支中替换 `ModerationService` 调用为真实 API
2. 将 API 返回结构映射为 `ModerationResult`（`passed` / `decision` / `reason` / `labels`）
3. 工作流侧无需任何改动

### 5.5 审核失败处理流程

```
moderateContent 返回 passed=false
    ↓
workflow handleSuccess:
    1. activities.releaseCredits(userId, workId, idempotencyKey)  ← 退款
    2. activities.updateWorkStatus(workId, FAILED, { stage: 'moderation_rejected', reason, labels })
    3. activities.notifyUser(userId, WORK_FAILED, { reason: '内容审核未通过：...' })
    4. return { status: FAILED, consumedCredits: 0 }
```

## 六、审核风险点评估

### 6.1 高风险项

| 风险项 | 风险等级 | 说明 | 应对措施 |
|-------|---------|------|---------|
| **算法备案缺失** | 🔴 高 | 深度合成类目强制要求算法备案证明 | 提供 Seedance（火山引擎）和通义（阿里云）的算法备案截图 + API 服务合同 |
| **AI 视频生成无专属类目** | 🔴 高 | 微信目前仅有 AI 绘画/AI 换脸/AI 问答三个深度合成子类目，无 AI 视频 | 归入"深度合成-AI 绘画"（视觉内容生成），提审时在备注说明 AI 视频功能；必要时与审核团队沟通 |
| **内容安全审核仅为关键词过滤** | 🟡 中 | MVP 阶段关键词过滤覆盖面有限，审核团队可能认为不够 | 文档说明后续接入微信/阿里云内容安全 API 的计划；关键词库可持续扩充 |
| **虚拟物品支付合规** | 🟡 中 | 积分套餐属于虚拟物品，需明确非虚拟货币 | 用户协议已明确积分性质与退款政策；确保不涉及虚拟货币兑换法币 |

### 6.2 中风险项

| 风险项 | 风险等级 | 说明 | 应对措施 |
|-------|---------|------|---------|
| **用户生成内容版权** | 🟡 中 | AI 生成内容版权归属存在法律模糊地带 | 用户协议已明确用户生成内容归用户所有，平台拥有使用权；免责声明已覆盖 |
| **对标解析功能** | 🟡 中 | 解析竞品视频可能涉及版权问题 | 用户协议行为规范已禁止侵权行为；免责声明已明确用户自负责任 |
| **未成年人使用** | 🟡 中 | AI 工具可能被未成年人不当使用 | 隐私协议已包含儿童隐私条款；后续可在注册环节增加年龄确认 |
