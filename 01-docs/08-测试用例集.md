# ReelClone 测试用例集

> **版本**: v2.0.1（截图审计版）  
> **目标**: 基于截图视觉审计、流程映射与数据模型，为每个核心功能生成正向、边界、异常、UI 验证四类测试用例，确保开发可测试、验收有依据。  
> **用例编号规则**: `TC-{模块}-{序号}`，例如 `TC-USER-001`。

---

## 一、用例分类说明

| 分类 | 标识 | 说明 |
|------|------|------|
| 正向用例 | P | 正常操作流程，预期成功 |
| 边界用例 | B | 临界值、极限输入、空值 |
| 异常用例 | E | 网络中断、权限不足、积分不足、服务异常 |
| UI 验证用例 | U | 元素存在性、文案一致性、状态切换、视觉规范 |

### TC-PERF-001：首页加载性能

| 项目 | 内容 |
|------|------|
| 用例名称 | 首页首屏加载时间 |
| 分类 | P |
| 前置条件 | 冷启动小程序 |
| 测试步骤 | 打开首页并计时 |
| 预期结果 | 首屏加载时间 ≤2s（99 分位） |

### TC-PERF-002：作品列表加载性能

| 项目 | 内容 |
|------|------|
| 用例名称 | 我的作品列表滚动加载 |
| 分类 | P |
| 前置条件 | 有大量作品 |
| 测试步骤 | 1. 进入我的作品<br>2. 快速滚动到底部 |
| 预期结果 | 单次 20 条加载 ≤1s，无卡顿 |

### TC-PERF-003：对标解析耗时

| 项目 | 内容 |
|------|------|
| 用例名称 | 30 秒视频对标解析耗时 |
| 分类 | P |
| 前置条件 | 积分充足 |
| 测试步骤 | 提交一个 30 秒抖音视频链接 |
| 预期结果 | 解析完成时间 ≤5 分钟（不含模型排队） |

## 二十、用例优先级与执行建议

### 优先级分布

| 优先级 | 用例数量 | 覆盖范围 |
|--------|----------|----------|
| P0 | 30+ | 登录、生成、支付、对标解析、作品/资产管理 |
| P1 | 20+ | 推荐、模板收藏、设置、关于 |
| P2 | 10+ | 兼容性、性能、安全深度测试 |

### 执行顺序

1. **冒烟测试**: TC-USER-001, TC-HOME-001, TC-TEXT-001, TC-VIDEO-001, TC-MINE-001
2. **核心功能回归**: 所有 P 类正向用例
3. **边界与异常**: 所有 B/E 类用例
4. **UI 一致性**: 所有 U 类用例
5. **E2E 流程**: TC-E2E-001, TC-E2E-002
6. **性能与安全**: TC-PERF-*, TC-SEC-*
